Mind to Machine Planner Brand guide, v2, 18 Nov 2026 Open the planner

One model reads. Code decides. Every number has a source.

The planner is read by judges under time pressure. The interface works like a printed report: one clear result at the top, then plain tables that show where each figure came from.

Type

One family: Söhne, falling back to the system UI font. Hierarchy comes from size and colour, not from weight or capitals. Code and the trace use the system monospace.

Colour

White page, near-black ink, slate for running text. Blue is the only accent: the headline, links, the primary button and the judging block. Status is shown with coloured words only, never with filled badges.

Layout

Single column, 1200 px wide, 40 px margins. Sections are separated by a black rule and a heading, not by boxes. Tables use a black header rule and grey row rules. Numbers are right-aligned with tabular figures.

No cards, shadows, pills, gradients, icons or uppercase labels. Corners are 4 px on inputs and buttons only.

The page always reads in this order: the result, the six checks, the key figures, then the detail.

Writing

Every decision states what was claimed, what was computed, and what happens next. Use full sentences. Write money as Rs 597,400 and time as 13:00.

Write

Box count is derived, not set by a vendor. Boxes equal headcount: 150 students, 17 judges and 10 staff make 177. The order stays at 177.
